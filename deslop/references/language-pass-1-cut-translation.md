# L1：禁句、空话与中文表达

**替换后自检**：用新句替掉命中项后，读一遍新句和相邻句，确认没有引入新的空话、事实漂移或指代问题。否定转正禁句必须清零，其余不要求按词表把命中清零。句式改写不得把无来源的判断洗成事实；依据不足时保留原有限定或标记待核，不以牺牲准确性换取清零。

## 1. 句式与零信息表达

否定转正禁句执行下列零次要求；其他句式按语境判断，引用原话和代码按原意保护。不得改动代码和 URL 来消除句式命中。

- **否定转正句式完全禁用，零次。** “不是 A，而是 B”及省略“而”的“不是 A，是 B”“不是 A 是 B”，以及“不只是 A，而是 B”“不在 A，在 B”“不看 A，看 B”“不靠 A，而靠 B”“不取决于 A，取决于 B”等同一骨架，一律改成正面陈述；真实对照、纠正误解也不例外。先明确对象、动作、结果，再核对被排除范围、比较条件和不确定性是否保留；必要排除关系可另用普通否定说明，不能把排除 A 升级成无证据的肯定 B。普通否定、数值限定、必要条件与“虽然……但是……”不在禁用范围；不要为避句式删掉事实边界。
- **消除免责声明式密集否定。** 对「不是 X」「不衡量 Y」等连续排除句逐段检查：已明确指标、任务、样本及范围时，删掉对假想误读的重复澄清，直接写测量了什么及结果；必要边界就近并入实验条件或图注，确保不扩大事实范围。不可仅因普通否定不属禁句就全部保留。
- **覆盖全部文本，引用无豁免。** 检查标题、正文、人物引用、图注和 alt。含禁句的来源原话须准确转述并明确归因，不能把改写伪装成直接引语；无法安全转述时保持原文并说明待核实，未解决前不能报零命中。不得为处理图中文字擅自修改图片。
- “X 才是 Y”“只有……才”在承担必要条件或可核实前提时保留；判断被抬成必要条件，或只在段末制造格言效果时改成直接判断或事实条件。时间、程度义和可核实的事实性前提不判错。
- **把判断外包给未来观察的句子先补判断依据**：“验收要看 X”“关键 / 最该看的是 X”“成败取决于 X”“能不能成 / 能否跑通”“真正的信号是 X”“还有两件事没有发生”“有待观察 / 还需时间检验”。如果句子已经写明谁在负责、依据什么、当前停在哪一层，保留；只剩观察清单时，改成已披露的分工、条款和当前能力层级，或对方已经承诺的可核实动作。`##` 标题和导读同等处理。结尾整体框架仍由 L3 裁决。
- 删除“今天我们来聊 / 本文将分析 / 以下是 / 结构如下 / 综上所述 / 希望对你有帮助”等机器人或交作业话术。
- **句尾拔高子句逐处判断**。事实说完后挂在句尾的意义尾巴——`……，体现了 / 彰显了 / 凸显了 / 反映了 / 见证了 / 印证了……`、`为……注入新活力`、`书写了新篇章`——确认没有新增事实时整截删掉。句尾推论“这意味着 / 这说明”先过三问：谁在推论、根据什么、删掉是否丢判断；答不上来整句删，答得上来并进前文事实句。
- **假揭示骨架改写**：“看似 X，本质 Y”“表面 X，背后 Y”里 X/Y 只是两个抽象评价时，先给事实再直接归因；不许换成“乍看 / 究其根本 / 说到底”继续揭示，换揭示词是同一骨架换外衣。
- **假平衡骑墙改写**：“各有优缺点 / 见仁见智 / 没有标准答案 / 取决于多方面因素 / 因人而异”——选边，或写清什么条件下选 A、什么条件下选 B。给出具体选择条件的放行。
- **评级悬念段首按作用判断**：“最反直觉的是 / 有意思的是 / 最容易踩坑的是 / 更微妙的是 / 看点全在 / 关键全在 / 核心就在 / 真正的重点在 / 亮点全在 / 精华全在”先盖评级戳再陈述。先判断该点是否真的是全文最重的点；不是就删前缀直接陈述，是也优先用陈述句。判据是删掉后信息还在不在、换成陈述句是否更顺。
- 删除假坦诚开场钩子：“说实话 / 老实讲 / 讲真 / 不骗你”。
- 万能受众套语（“无论你是新手还是专家”）和预设读者内心状态（“你会发现 / 你会自然地问 / 你是不是也觉得”）改事实陈述，去“你”。
- 意义拔高句和判断句执行**抽主词测试**：把主语换成任何一个同类主题，句子照样成立就是没承载本文独有信息的空话，还原成具体事实或删。
- 删除“这句话很重要 / 答案特别直接 / 结论很克制 / 说得很清楚：”等评价层。程度副词加抽象评价的冒号句先问删掉评价后事实是否仍在；在就删评价，引用前只写谁说的。最后一章的“最终判断很明确 / 某主体的警告很直接 / 本章的结论是”同样直接写判断或归因。
- **模糊归因须核对来源。** “专家认为 / 业内普遍认为 / 研究表明”等表达，原文或用户提供的材料有具体来源时写明；没有来源时保留原有归因和不确定性并标记待核，不虚构专家、机构或研究，也不直接删掉可能重要的事实。
- 万能开头“随着……的不断发展 / 在当今……的时代 / 在……的背景下 / 众所周知 / 毋庸置疑”删除。“近年来”只有确实限定来源时间范围时保留。
- 分人群提纲句改成事实与机制本身，不点名读者画像。
- “说白了 / 其实 / 换句话说 / 也就是说”只作调味时删除。固定“证据边界 / 值得注意的是 / 小结”标签融进自然陈述。
- 删除未来可期、拭目以待、站在新起点、通用挑战、过度谦虚和机器人收尾。结尾框架由 L3 裁决。

## 2. 生活场景类比、评测术语与让步转折

**生活场景类比按可理解性判断。** 考试、上课、比赛、打仗、做饭这类场景如果只是把领域术语换成日常说法，或让读者以为在讲另一件事，还原成领域本来的说法：`考题` 是评测任务，`阅卷` 是打分，`成绩单` 是分数表，`补课` 是继续训练。若一个类比确实降低理解成本、且随后用直接中文解释机制，可以保留；让一个场景充当全文骨架、每章回到同一场景时，才拆掉整条线。不设类比数量配额。正文、导读、标题和图内文字同一标准。

**评测术语用全称。** 首次出现写「大模型评测 benchmark」或「评测集」并说明它测什么，不把「基准」单独当名词用（`发布基准` 读不出在说什么）。评分细则、评分项、任务、单次作答照字面写。

**让步转折说明真实关系。** `题本身没问题，但凭经验想出来的修改分布不同` 这类先肯定再否定，如果一段里连着出现，读者每句都要重新校准立场；能直接给结论就直接给（`专家凭经验设计的修改，分布和真实工作流不一样`）。除第 1 节禁句外，承担真实让步或事实对照的句子保留，不按出现次数判错。

## 3. 功能性比喻与装饰性比喻

比喻的判断标准是“降低理解成本”还是“只增加形象感”。功能性比喻把陌生机制映射到已有经验，且比直接术语更容易理解，例如“相当于给 AI 配备了一个完整的虚拟实验室”；随后用直接中文解释机制，用完即弃。只拟人化技术量或换形象动词不算功能性比喻：`方程没跟着变胖`应写`方程复杂度没有同步上升`。

删除不解释机制的意象包装和贯穿全文的意象装置。功能性比喻只在比直接术语更容易理解时保留，用完即弃，不设数量配额。**借喻场混用按读者是否需要重新建立映射判断**：短距离内混用多套不相干比喻、让读者跟不上时，还原成本义；几个比喻各承担不同机制时不必机械删。

## 4. 直接中文

- 被认为、被广泛应用、被视为优先改成真实主体做动作；“进行了讨论 / 做出了决定 / 实现了增长”改为“讨论了 / 决定 / 增长”。能写“是 / 有 / 可以”，不用“作为 / 具备 / 设有 / 呈现出特征”绕一圈。转主动不得新增“我”。
- **「把」字句按自然搭配和施受关系判断。** 「把」本身不是错误；只有当宾语提前后句子变长、动作层次不清、施受关系可能反转，或写成 `把[A]进行[B]` 这类绕行动宾时，才改成直接动宾或拆句。处置义清楚、没有更自然说法的句子保留。引用原话除外。改完重读该句，确认施受关系没有反转。
- 多层 who / which / that 式前置修饰改为谓语或后置说明。连续 3 个以上“的”只作报警信号，固定术语和必要所属保留。
- “在……方面 / 对于……来说 / 通过使用……”能删就删，“通过使用”通常改“用”。时间、地点和必要条件放到动作前。
- “可能潜在地被认为”只留一个承担不确定性的限定词。具体、有证据的限定词保留；证据确有不确定性时可用准确限定，不得削弱确定事实。
- 单个必要连接词可保留；同段密集出现“此外 / 与此同时 / 事实上 / 值得注意的是”才处理，仍逐句判断。
- 英文数字格式按中文习惯写，如 `1,000,000` → `100 万`、`百分之五十` → `50%`；保留原始精度、单位和字段，不四舍五入。

**破折号按用途判断**：只有制造停顿、补充解释或转折确有用处时保留；同一段多处、用破折号代替句号、或删掉后句子更顺时改成逗号、句号或拆句。不按符号本身判错，也不要求清零。引用原话中的破折号按原意保护。

**词频和标点计数只作定位信号，不设硬配额。** 虚词、成语、程度副词、感叹号、路标词、把字句频率和问句数量都不能单独判定 AI 味；先看句子是否承担信息、是否与上下文自然衔接，再决定改不改。下列情况值得多看一眼，但不要求清零：同一段连接词和评价词密集；连续使用同一种反问或感叹；同一个词在同一段反复出现。

**中文搭配按语境判断。** 动词和宾语是否搭配自然，表达是否准确，而不是句子能否逐词翻回英文。真实工程动作与稳定用语保留，不凭风险动词词表替换。主语、指代和术语的全量检查留给 L2；L1 改句后按共享契约局部自检，确认施受关系、指代和含义没有变。

## 5. 官腔、宣传词与伪深度

以下只作风险信号，按语境删除或改成具体原因、动作、指标，不机械替换：

- 赋能、深耕、聚焦、助力、打造、引领、全方位、多维度、高质量、沉浸式、一站式、底层逻辑、顶层设计、新质生产力、降本增效、提质增效、数智化。
- 亮眼、瞩目、欣欣向荣、蓬勃发展、硕果累累、令人振奋、可圈可点、有目共睹、蒸蒸日上、日新月异、突飞猛进、如火如荼、方兴未艾、势不可挡、开创性、里程碑式。
- 认知升级、思维模型、元认知、第一性原理、范式转移、颗粒度、飞轮效应、杠杆、势能。
- 至关重要、深入探讨、不断演变的格局、彰显、凸显、关键性作用、持久影响。
- 英文 AI 高频词的中文伪装（洋腔）：深入研究（delve）、见证（testament）、格局（landscape）、无缝（seamless）、拥抱（embrace）、解锁（unlock）。命中时换成具体事实或平实说法。

标准学术或政策概念可保留。四字格本身无错；同段堆叠多个陈词滥调时改成谁做了什么、结果如何。
