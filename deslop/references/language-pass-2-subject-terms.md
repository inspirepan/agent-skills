# L2：主语、动词、术语和“这 / 那”指代

## 1. 主语、代词与动作

- 中文允许省略已明确主语。连续“它 / 他们 / 我们 / 该系统”可省略或合并动作；同段反复写全名时自然省略，不为避重生造同义称呼。
- “我们可以看到 / 他们发现”只用于引出事实时，直接写观察结果。
- 段首“它 / 其 / 前者 / 后者 / 基于此”没有明确对象时换具体名词。“就是 / 也正是 / 本质上”让本段悬空时改为直接判断，必要时补半句前文事实。
- 检查谁执行动作、谁承受结果是否清楚。定义、配置和状态可以直接说明，不按“是 / 为 / 属于”的次数改写，也不为了动作感强造主体或改变事实口径。

## 2. “这 / 那”专项

搜索以下词，逐处看指代是否清楚：`这 / 那 / 这个 / 那个 / 这些 / 那些 / 这种 / 那种 / 这类 / 那类 / 这里 / 那里 / 这样 / 那样 / 这份 / 这场 / 这项 / 这件 / 这条 / 这一步 / 这一层 / 这意味着`。

每个命中判断指代对象是否清楚，不要求删减或逐项留档。指向明确、能自然承接时保留；指向多个对象、需要回看，或换成具体名词更清楚时换名词。引用块、代码块、截图 alt 和专有名词不机械处理。

## 3. 动词、官腔与具体动作

动词让读者猜不出实际动作时，按语境写清接收、读取、根据结果调整或完成验证等含义。工程语境中“跑通 CI”“数据闭环”若链路和结果明确可以保留。

**编辑归纳与来源动作分清。** “拆开看”“归纳”“划分”等词可用于解释分类和口径，但须给出具体内容，不能把编辑的分析写成研究者或 Agent 实际执行过的步骤。抽象主语也不自动判错；检查动作关系是否明确，不凭词形改写。正文、导读和标题同一标准。

不要用另一个万能黑话替换。真实动作和链路明确的工程词汇不机械判错。模糊程度评价改成可核实的动作、结果或判断标准；有上下文和对象支撑的程度判断可以保留。

## 4. 术语、英文和比较句

1. 产品名、模型名和 API 名保留英文，如 Claude、OpenReview、API。
2. 必要标准术语首次出现时，用一句直接中文说明它是什么、在流程中做什么；必要时括号保留英文一次。
3. 内部阶段名、评测器名和可替换黑话改成动作或判断，不让读者背词。

不要用中文黑话机械替换英文黑话。遮住英文术语后，读者仍应能复述输入、判断和输出。常见改法：`prior art collision` → “核对前人是否做过同一机制”；`audit context` → “检查候选时的参考信息”；`kill-switch` → “不能被后续改写的证伪条件”；`method-lineage tree` → “方法谱系树：把基础方法和历次改进按继承关系排起来”；`saturation` → “某种模式在邻近文献中的使用频率”；`seed` 按语境写“测试方向 / 初始问题”，实验协议需要时首次写“测试方向（seed）”；真实输出值 `advance / revise / abandon` 先解释“推进 / 修改 / 放弃”，再保留代码值。

全文括号英文注释按理解需要保留，不设次数配额。合法中英混排、模型名、产品名、标准术语、图片路径、代码字符串和来源 URL 保留。

比较句在语言层面必须写明和谁比、比什么、在哪个范围。只补句子缺失的参照，不重新裁决实验可比性；无法安全补充时说明待核实，不猜。

**“从 X 到 Y”须表达真实范围。** 两端有明确的时间、数值、空间或流程关系时保留；只是罗列主题时直接列举，如“从架构到用户体验”按语境改为“架构和用户体验”。不得改动真实范围、流程顺序或覆盖边界。

**技术说明使用准确名称和操作顺序。** 文件名、标识符、参数和命令在原文或用户提供的材料中已明确时，用准确名称代替容易混淆的泛称，保留大小写、路径和参数写法。操作步骤先写适用条件，再写动作；已有警告放在对应的危险操作之前。只调整已有信息，不推测名称、补造命令或新增操作要求；普通消息和非操作性文本不强套此格式。

**量词和介词按信息作用保留。** “一种 / 一位 / 一项”和“在……过程中 / ……情况下”等表达可以限定对象、范围和条件，不因能删除后仍合语法就删。只处理重复或绕远的表达，不把常见中文结构判成英文残影。

**保护清单与保真回读（本轮全程）。** 动手前先在心里圈出五类保护项：数字（“约 42%”不能变“超过四成”）、专有名词、URL 与链接文字、真实姓名与引语、承诺条款。改完全文逐项核对：数字和它修饰的对象配对保留（“p95 从 480ms 降到 160ms”不许概括成“明显降低”）；关系、时间跨度、责任归属不漂移（“展示潜力”≠“采用架构”，“两个团队”≠“换过两个团队”）；不新增原文没有的事实、不把排除关系升级成肯定事实（“问题不能归因于大家不够努力”≠“大家一直很努力”）。**换汤不换药**：删“标志着”不能补“象征着”，删“赋能”不能补“加值”。
