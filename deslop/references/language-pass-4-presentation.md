# L4：段落、加粗、Markdown 与 alt

## 1. 句群与段落节奏

- **段落主题要容易找到。** 首句给主题通常有效，但不是固定位置要求。若一段先建立案例、条件或上下文，最后才落到判断，只要读者能跟上就不判错。把各段首句抄到一起只作定位，不要求串成全文骨架；一段确实装了两个互不相关的主题时分段。
- **同一动作链保持关系完整。** 分句或分段造成输入、动作和结果脱节时补承接或合并；不因主语相同就硬合成长句，也不因用了分号就改写。
- 一个句子同时装观点、原因、例子和结论时按语义拆分。同一主语的连续动作、同一实验的控制条件、同一阶段的输入输出不拆成口号短句。连续几句过短、共享主语或必须回看才懂时，合并可能更顺，但按实际读感决定，不按字数自动拆合。
- **避免过度压缩。** 箭头、缩写或省略主语和动词让读者需要解码时，补成关系完整的句子，如“解析失败 → 退出 2，不写入”改为“解析失败时，程序以退出码 2 结束，不写入数据”。只补原文已明确的关系；用户要求的大纲、速记格式，以及清楚的流程图、代码和固定缩写保留，不为完整句强改格式。
- 按语义单元切段，完整案例、必要上下文和一条推理链可以写长，读者能跟上就不按臃肿处理。人物原话按理解需要取舍，不为缩段改变原意。
- “现象 → 机制 → 结论”“质疑 → 拆解 → 判断”“条件 → 结果 → 边界”这些链路在同一段内通常更容易读懂，但不强制在一段走完。只要语义边界清楚、读者不用回看，拆成相邻两段也可以；不在逗号处机械换行。
- 相邻两三段属于同一推理链时可以合并。段落长度只作建议，不按字数自动判错。章节开头连续两段背景长句、判断埋在第三层从句或单段两个以上分号时优先复查。
- 句长、段长或起句相似只作读感观察，不据此判定作者身份；内容并不重复、读起来顺畅时保留，不为反模板故意改长短。
- **节奏检查不设数字配额**：句长、感叹号、路标词和行数只作观察角度。只在帮助理解时设问或转折，不硬插钩子。删句前同时检查事实、因果、指代和阅读衔接是否受损，不机械清零。
- **括号按用途判断**：插入成分遮住句子主干时，把重要说明移进正文，删掉无关内容，不按括号次数改写。省略号只留真实停顿，不连续制造余韵。
- 单句段只复读所在 `##` 标题时，删除复读部分或把唯一新增信息并入下一句；若它承担过渡或补足上文，保留必要部分。不要随机拆句、换行、插入口语或制造语病。出声朗读关键段，处理一口气读不完、主判断到段末才出现、企业通稿、客服话术、逐句硬译或 PPT 报幕的具体原因。

## 2. 加粗与引用

加粗用于帮助扫读。锚点按语气重音落在判断、机制、定义或结论的半句，嵌在句中。密度随内容起伏，不按段数配额。“连续三段无加粗”本身不算问题。

改掉整段加粗、只加粗连接词、裸数字、只加粗枚举编号。同一段加粗过多、全章只加粗数字、机械等距或类型全同时检查是否争夺重点；按信息层次调整，不按处数配额。引用块已有视觉区隔，不整段加粗。

含禁句的引语按 L1 准确转述并归因，不冒充直接引语；无法安全转述则保留原文并说明待核实。

## 3. Markdown 骨架

1. 分类、失败模式或真实步骤可用有序列表、无序列表或分段，按读者是否容易理解来选，不设条目数或全文次数配额；不要把连续推理拆成孤立要点。emoji、装饰符号和“**小标题：** 解释”式粗体列表不用来制造视觉热闹，编号不充当唯一锚点。
2. 标点卫生：惊叹号按语气使用，一段内连发时检查，不设全文配额；省略号只留真实停顿，不连续制造余韵；引号只用于直接引语、术语定义和真正反话，不给普通词架「」当强调（拿掉引号句子照样成立就是装饰）；书名号只用于真实作品名；中文行文标点统一全角，中英文之间空格的有无全文一致。
3. **三类残留逐处处理**：AI 工具残留（链接里的 `utm_source=chatgpt.com / openai`、`turn0search` 等引用残码、`【1†source】` 式残码）、未替换的占位符（`[产品名称]`、`待补充`）和 L1 禁用的否定转正句式。成稿中的占位符不代填，说明待补内容；模板中的有效占位符保留；禁句须正面陈述并保留事实边界，误报留裁决依据。其余标点、句式和词频命中只作定位建议，按语境判断，不要求清零。

## 4. 图片 alt 与图内文字

图片使用真实 `![alt](path)`。alt 准确概括内容，不写“图片 / 配图 / 示意图”空标签。逐个检查 alt；图内的大标题、模块标题、标签、图注和结论条按同样标准逐个检查，不能只审大标题或拼写。

图内标题和文字应自然、具体，准确描述图示；可用动作、明确话题或具体问句，不强制结论式陈述。其他可见文字按 L1–L3 三份清单的同名条目处理，事实口径不得改变。

## 5. 不要误判

保留真正承担转折的短句、必要长句与完整推理链，不按段落字数排除；图片路径、代码字符串、固定表达和来源 URL 按原意保护。不得为视觉整齐破坏语义。
