# L3：标题、开场、结尾与判断解释

## 1. 标题

逐个检查标题是否自然具体、与章节内容相符；可以用真实动作、场景、明确话题短语、具体问句或有依据的结论，不强制主体、结果或陈述句。语境清楚时优先短标题，不为语法完整重复正文。避免「这套系统值得复用的是……」之类替读者做价值判断的总结腔，用具体场景或操作承载信息。标题不强制同句式，冒号不设占比配额。不用空泛黑话、无法理解的内部名称、孤立数字或“回头看 / 再谈 / 继续说说”充当标题。英文人名如不足以帮助识别，可用读者认得的机构或身份指代；不要为了轮换给同一主体换名。

逐句判断是否提供新增事实、解释、必要衔接或限定；没有信息增量的重复、总结和评价句直接删去，不为显得完整保留。必要的样本、指标、对照、来源归属和局限不能省略。

正文和章节标题中的问句可以保留，具体且有回答即可；不设固定处数，只为制造悬念或正文未回答的问句才改。

**重复免责按作用去重，不设边界总数。** 只有删后不改变所在结论含义、也不损害理解的例行声明才去重。导读和正文证据处各自需要同一限定时，两处都保留；例如“仅在该留出集上优于专家”不能因正文再次交代测试范围就删去导读中的范围。必要边界随相关结论出现，数量由来源和解释需要决定，不把准确限定当成扫兴。

## 2. 开场

全文和各章优先用动作或困境切入；“X 是 Y”式定义句不是一律判错，对象必须先界定后文才能展开时可以用一句定义，但定义后要尽快进入动作和机制。动作切入指真实主体做出的真实动作；作者的分析动作（`把 X 拆成三段`、`梳理出四点`、`盘点了三类`）长得像动作，实际是替读者分类，不算动作切入，按 L2 的元分析动作处理。文章开场自然写谁做了什么、覆盖什么、核心机制或结果，不靠论文页数、上传动作、发布现场或悬念制造入口。

## 3. 结尾

全文结尾落在已确认事实的判断或最具体的事实上，直接回答主标题；可以写收束段，也可以自然停在关键事实，段数按内容需要决定。不凭空新增免责或局限，也不用“条件 + 前景”式展望升华。**结尾大词自查**：搜“时代 / 文明 / 未来 / 世界 / 历史 / 所有人”，正文没有在处理这个尺度时，结尾回到具体事实。

**把判断外包给未来观察的句子先补判断依据**：“验收要看 X”“关键 / 最该看的是 X”“成败取决于 X”“能不能成 / 能否跑通”“真正的信号是 X”“还有两件事没有发生”“有待观察”“还需时间检验”。如果句子已经写明谁在负责、依据什么、当前停在哪一层，保留；只剩观察清单时，改成已披露的分工、条款和当前进度（谁负责定哪项标准、合同里写了哪条拿钱条件、公开披露的能力停在哪一层），或对方已经承诺的可核实动作（`GEMSTONE 要为全网定出互操作标准`）。命中位置常在最后一个 `##` 标题和收束段，两处都改；正文中段命中同样处理。

最后一章自然完成解释即可，不强制新增判断或总结；已有内容讲清时可停在具体事实上。反复换词总结同一结论时删除重复；不擅自改主线。

## 4. 判断与解释

判断不是每篇固定几处态度句，也不是每章末尾都要表态。文章在需要读者知道“为什么这样选、这个结果意味着什么、证据能用到哪”的位置，把关键选择、取舍和证据解释清楚，判断就成立了。只写事实不给解释，和只写评价不给依据，都按理解问题处理。

- 判断只落在文中已经解释的机制、数据或取舍上，不新增来源没有的事实。
- 可以有立场，也可以用成功、失败、未定三种结论；不要求为了显得厉害改变结论方向。
- 不新增“我”、个人经历、情绪或虚构矛盾；不补无来源的现场细节（`凌晨三点`、`咖啡早就凉了`、`我愣了一下`）。来源自带或作者提供的细节照原样保留。
- 真实的口语判断、承认矛盾、让步和类比可以保留；空泛评价、模糊程度词和只制造情绪的短句按 L1 删除。
- 只制造戏剧停顿的一字转折（`但不是全胜`、`但问题来了`）删掉后信息不变，按空话处理；有真实转折内容时保留，不按出现次数判错。
- 不要求每章都有作者态度，也不按判断句数量判定完成度。作者没有给出的立场、故事或转折不得发明。
- 引用原话中的真实第一人称和设问按原意保护。

**删掉空话后如果段落只剩术语或事实清单，补回读者缺少的背景、因果或完整案例。** 补解释按理解需要，不套让步翻转、微讽、短句封口或情绪反应模板；没有缺口就不补。

**通读残留按实际影响处理。** 开场套话、段末总结、远距离叙述、换主词照样成立的句子和等长句，只在确实妨碍阅读或显得机械时改；不要求清零，也不为制造“人味”刻意留痕。

**图片前后的正文写读者应得到的判断、机制、反差或证据边界。** 不按画面顺序复述「图把什么排在一起」「图上标着什么」「左边是什么、右边是什么」，也不要用「图中 / 图上 / 这张图 / 该图」串起整段免责声明。需要限定口径时先给判断，再用计算方法、比较对象或样本范围解释。只有坐标、图例或视觉编码会改变结论，或不解释就会误读时，才保留一句读图说明。图片与正文共享同一机制时，正文可以保留必要的解释；只有重复展开同一组节点或数字时才删。
